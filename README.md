## Visited Places App

## Description
This app allows users to record and review places they have visited.
Users can add descriptions, choose categories, and rate their experiece.

## Author
Jeshurun Mwangi

## Features
Add place review
choose category
choose experience rating
saves data locally
Displays saved reviews

## Technologies used
HTML
CSS
JAvascript
LocalStorage

## Setup Instructions
1. Download or clone the project
2. Open index.html in a browser
